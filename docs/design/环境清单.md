### 8.3 常见环境问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `'node' is not recognized` | 终端是旧环境（启动早于 Node 安装/PATH 修改） | 完全关闭 Windows Terminal / VS Code 后重开，或重启资源管理器/电脑 |
| PowerShell 中 `npm` 报 `npm.ps1 cannot be loaded` | 执行策略为 Restricted | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，或改用 `npm.cmd` |
| `pnpm` 找不到 | 未安装 pnpm | `npm install -g pnpm` |
| `mvn` 找不到 | Maven 未加入 PATH | 使用 `scripts\start-backend.cmd`，或把 `E:\apache-maven\apache-maven-3.9.14\bin` 加入 PATH |
| `mvn package` 报 `TypeTag :: UNKNOWN` | 使用 JDK 24 编译，Lombok 不兼容 | 设置 `JAVA_HOME=E:\Java\jdk-21`，或使用项目启动脚本 |
| `Could not create local repository at D:\maven-repo` | 全局 `settings.xml` 指向不存在的目录 | 改用 `-Dmaven.repo.local=项目\.m2repo`，或修改 settings |
| 5173 打不开 | 前端未启动/Node 不可用 | 新终端执行 `npm run dev` 或 `scripts\start-frontend.cmd` |

| E-06 | D 盘仅剩 2.1 GB | 构建、日志、备份空间偏紧 | 清理或迁移项目/仓库 |
| E-07 | 项目未初始化 Git 仓库 | 无版本记录与回滚能力 | `git init`（可选） |
| E-08 | CPU 型号/内存未采集 | 无法核对硬件余量 | 任务管理器 → 性能查看 |
| E-09 | 前端开发服务器由外部进程启动 | 无受管启动脚本/日志 | 需要重启时用 `npm run dev` 或 `scripts\start-frontend.cmd` |

> 以上均不影响当前已运行的前后端；E-01～E-05 影响“重新构建/重装依赖”的体验。

## 10. 从零搭建步骤（换机参考）

1. **安装 JDK 21**，设置 `JAVA_HOME`，确认 `java -version` 为 21。
2. **安装 Maven 3.9**，加入 PATH；将本地仓库设为可写目录（或使用项目 `.m2repo`）。
3. **安装 MySQL 8.0**，启动服务，创建数据库账号。
4. **安装 Node.js LTS**，确认 `node`、`npm` 在 PATH；需要 pnpm 时执行 `npm install -g pnpm`。
5. （可选）安装 Git、IntelliJ IDEA / VS Code。
6. 获取项目代码，确认目录结构完整。
7. 初始化数据库：`scripts\init-db.ps1` 或手工执行 `schema.sql` + `seed.sql`。
8. 构建并启动后端：`scripts\start-backend.ps1`（自动处理 JDK 21 与 `.m2repo`）。
9. 安装并启动前端：`cd frontend` → `pnpm install`（或 `npm install`）→ `pnpm dev`（或 `npm run dev`）。
10. 验证：`node scripts\smoke-test.mjs`，预期 52 项全部通过。

## 11. 安全与使用注意

1. 数据库默认密码与 JWT 默认密钥仅适用于本机演示，部署前必须通过环境变量覆盖。
2. `frontend/.npmrc` 与 `pnpm-workspace.yaml` 是为当前 Windows 环境准备的（hoisted、项目内 store），换机可保留。
3. `backend/uploads` 为用户上传目录，不应提交到版本库；生产建议使用对象存储并增加类型/大小/病毒校验。
4. 本项目不提供在线支付与物流，交易均为校内线下完成。
5. 演示账号仅用于课程演示，不应在公网环境直接使用。

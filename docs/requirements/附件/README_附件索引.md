## 4. 使用注意

- 所有 `【待填写】`、`待确认` 和 `未开展` 项必须由小组按真实情况处理。
- SVG 可直接用浏览器打开；源文件可使用 Mermaid Live Editor 或 PlantUML 编辑器重新渲染。
- 可点击原型仅用于需求走查，所有数据为本地模拟，不能证明后端功能、安全、并发或持久化已实现。
- 若修改需求或规则，请同步修改 SRS、A 报告、B 报告、模型、E-03 和原型，并更新 E-07 哈希。

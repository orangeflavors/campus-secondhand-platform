原型走查指南

按 A 报告 PV-01～PV-04、PV-05a/PV-05b、PV-06～PV-07 操作并保存实际观察证据。

  • PV-01 买家：搜索“教材” → 选择教材资料 → 收藏。
  • PV-02 卖家：发布商品 → 管理员：审核通过 → 买家：确认能搜索到。
  • PV-03 买家：创建待确认请求 → 卖家：接受 → 买家/卖家依次确认 → 订单完成。
  • PV-04 未认证用户：尝试发布或创建待确认请求 → 确认被拒且状态不变。
  • PV-05a 两条待确认请求：接受一条后另一条未中选取消。
  • PV-05b 并发接受：本原型无法验证，必须在后端实现后测试。
  • PV-06 单方确认后：尝试取消 → 应提示改走争议。
  • PV-07 买家：举报商品 → 管理员：判定成立并下架。

证据要求：每个场景至少保存关键操作前、提示、状态结果三类截图；记录验证者、日期、输入、实际结果和问题。页面走查通过不代表后端业务已实现。
